# Phase 1I qualification

The selected blanket completion claim is **falsified**. The frozen K1 contract's
resource entitlement is insufficient for its parallel context in the existing
runtime: ordinary root **local** success closes admission before an independently open
peer can invoke S. Both independently authored candidates exhibit this failure.
The contract and its original 84 entitled configurations remain unchanged.
This is a failed `C[K1] satisfies Gc` premise, not a refutation of an implication
that assumes that premise, nor of Definition 4.6 using unequal-charge candidates.

Other results are bounded and separate: application correlation/complement and
resource-envelope checks hold in the enumerated positive graphs; all 76 entitled
nonparallel configurations complete. Sampled public-runtime execution, process
recovery and uncertainty checks support their stated schedules. No universal
substitution, compiler-correctness or unbounded progress result is claimed.

- The initial specification was rejected for underspecified local refinement,
  entitlement and absent-response/context behavior. Original draft and corrections
  remain in [review evidence](evidence/reviews/); exact-digest rereview approved it.
- Reference v1 collapsed failed-child consumption and terminal freeze. V2 then
  leaked child payload into parent failure/absence/pending. Original sources,
  censuses and direct RED regression remain; v3 separates the state. The original
  prefix oracle is unchanged. The boundary extension's first cancellation-reason
  test also failed and is retained.
- Initial runtime normalization/membership and live ACK/assertion failures remain
  under [runtime development evidence](evidence/runtime/development/). The fixed
  assertion distinguishes the authentic original receipt from a separate later
  source-denied operation; it does not delete the latter result.
- Independent review exposed five corrupt-inspection inputs that normalization
  wrongly accepted and 18 original cancellation records mislabeled `Closed=false`.
  A separate raw-consistency check now validates selected observations/receive
  handles, identity/provenance/generation and local terminal/freezes before
  normalization; consumption uses the actual selected payload. The unchanged K1
  behavioral oracle remains separate. [Scoped rereview](evidence/reviews/decoder-rereview-v2.md)
  approved the fixes after 61 focused cases. These mutations test the decoder,
  not a claim that the production runtime emitted inconsistent records.
- Final review found that the first equal-charge model used B-derived surrogate
  control and the weak helper's payload differed from its actual artifact.
  [Actual probe mapping](evidence/model/probe-artifacts/correspondence.json) now
  covers all 41 instructions of six programs; RED regressions and original
  surrogate results remain. Current equality covers the original protocol only;
  sampled boundary-extended runtime membership is checked separately.
- Current model/process tests do not prove arbitrary-context equivalence, fair
  completion under infinite interference, compiler correctness, or distributed
  fencing. Fresh deployment is the substitution boundary; retained-code
  replacement/migration is excluded. No business exactly-once conclusion follows.
- The manuscript's affected Markdown and LaTeX claims are synchronized; changed
  TeX sections compile. Full compilation stops at the pre-existing undefined
  `\llbracket` on line 215; no complete-PDF claim. General loop ranking and the
  now-explicit congruence/future-recovery obligations remain open.
