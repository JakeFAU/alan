## Reproduction and findings during qualification

Run from the repository root with the offline readonly Go/CGO settings in the runbook. Each output directory must be new. The driver builds both actual executables with the selected regime. It requires loopback TCP, signals and local SQLite. For the checked campaigns the driver SHA-256 was `595942b9ebedc2cc1b96e7aa6c395a3da86874e16452848fbb97349b24385c7c`.

```sh
python3 examples/reconciliation/consumer/qualify.py normal /tmp/alan-public-normal
python3 examples/reconciliation/consumer/qualify.py race /tmp/alan-public-race
go -C examples/reconciliation/consumer test -count=1 -v ./...
go -C examples/reconciliation/consumer test -race -count=1 -v ./...
go test -count=1 -v ./examples/reconciliation
go test -race -count=1 -v ./examples/reconciliation
```

For an already seeded example the executable supports `issue -db PATH -endpoint LEDGER_APPLY_URL`, `resolve` with the same flags, `refresh` for a separately provisioned second query, and read-only `replay -db PATH`. `init -db PATH -endpoint LEDGER_APPLY_URL` provisions the default. Add `-observe-original=true` for the selected-failure source or `-adopt=false` for read-only authority. The controlled post-commit hold and owner kill in the qualification driver establish the missing-result cut. Simply issuing an operation to a responsive endpoint generally retains its result normally.

The initial sandbox run could not bind the endpoint. Once loopback was available, the positive ran, but the first CLI implementation could not locate an issuer whose failed invocation was already published. A published `PrepareInvocation` result omits the earlier freeze. The corrected CLI obtains membership from the existing admitted invocation after a successful preparation check. The corrected normal and race campaigns passed, followed by a second pair that checked the selected observation bytes and terminal projection explicitly. The checked runs are distinct from the earlier captures. The public module passed vet and module verification.
