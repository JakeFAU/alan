# Finite operation, read and adoption model

This model asks whether the state transitions themselves distinguish a previously applied original from a lost local response, and whether a justified new import can advance ordinary control. It imports no executor, SQL, effects package, Go fixture or endpoint decoder. The [frozen bounds](01-source-and-matrix.md) restrict one original, two logical lookups and two physical opportunities per logical lookup. Profiles represent experimental cuts. The [Go transition table](../../../research/reconciliation/model.go), [full export](evidence/model/graphs.jsonl.gz), [per-profile counts](evidence/model/summary.json) and [shortest adverse traces](evidence/model/traces.json) identify the domain of each result.

## States and scheduler

A graph line contains Profile and Rows. Each row has a State, a diagnostic Class and every labelled Edge to an indexed row. Rows are discovered in breadth-first order. Edge generation precedes target deduplication. The initial state has one authorized, charged original, a fixed exact binding (symbol 1) and a prepared consideration. The symbol stands for the tuple of namespace, original generation/operation, permission/attempt, ledger/protocol, key, wire, schema and policy. Symbol 2 denotes a different tuple. Strings, digest preimages, deployed schema checks, authorization revisions and handoff byte encoding are refined only by source and concrete tests.

* An original consideration admits if open or refuses after R. An admitted opportunity enters the physical call, the endpoint accepts a packet, and independent world service can apply it. For a raw multiplicity ablation a second independently submitted original packet can also apply. A regular return with unavailable local evidence can finish H. The retained-failure profile records, settles and selects its original unsuccessful interaction before R. Q requires durable R, current ownership and a handled original. The race profile enables R on either side of admission and services a pre-admission refusal before asking Q. The real wait can also finish before a parked pre-admission consideration returns. Other profiles deliberately restrict R to their stated cuts. In the paired original loss profile the owner can be killed after R at admitted/pre-call or returned/pre-record. A subsequent fresh Open/target Q leaves different world histories with identical local facts. In the delayed-packet profile a kill can intervene while the accepted packet is held. In both profiles the crash removes local original work; it preserves the external packet.
* A first ordinary query is issued only after Q, as in the principal service schedule. A second refresh can issue after selection of the prior query. In the two-resolver profile another live resolver can instead issue a concurrent, separately identified query. Request commits a logical debit. A fresh eligible admission binds target 1 and increments that logical request's durable ordinal before entry. Wrong target and two prior expenditures yield local retained refusals. Closure after the query reservation but before its current gate withholds that exposure, leaves no terminal result and allows resolver Q. The logical refusal abstracts the local classification and omits any world snapshot. A capacity-held reader may revoke, and an independent peer may commit while that call is outstanding. The model's separate resolver Q can observe a revoked resolver with no admitted work or after its H. Checking source scope, fairness and local mutex service in the general executor remains outside this finite machine.
* Each read entry either suffers the selected transport failure or creates a separately identified endpoint snapshot. No applications at that moment give absence, one exact application gives found, and two give ambiguity. A malformed or foreign-bound response cannot become a retained world observation. The model projects the concrete none decision for absence or transport failure, and conflict for ambiguity, into the Outcome field with an empty Adoption. The real snapshot table keeps its audit history even if the receiving owner dies. Subsequent query return and local retention are distinct transitions. At retention, a found response can supply the single original reconstructed result only when the exact target and import grant match, the staged original is missing and its policy is supported. A previous unsuccessful interaction remains intact. Another genuine found query can point to the existing reconstructed result. Raw evidence, denied import, incompatible policy, unsuccessful transport, ambiguity and provisional absence have distinct outcomes. Each logical query can retain at most one terminal result.
* During an owner loss the opportunity disappears and the expenditure survives. The possible query losses in their respective profiles are before send (twice), after snapshot, after return or after atomic retention/import. Open rechecks original Q and must first settle any surviving known original result. Only a still-missing logical result permits another eligible physical attempt. A committed result resumes its remaining local handling. Original settlement, original aggregate publication, selection of that public outcome, settled resolver evidence selection and the parent's last guarded use are distinct. In the concrete program the evidence observation is selected by the resolver and forwarded in a typed ordinary message. The model collapses its successful transfer and the caller's receipt selection. The sequential two-query program forwards only its final result. If its first read adopts, its second reports duplicate and the actual success guard rejects. With two concurrently entitled resolvers the abstract recipient can receive the importing resolver’s report. The concrete two-resolver history qualifies the import race only. Duplicate handling can precede original settlement because that resolver owes only its own accounting. The frozen constructor and concrete consumer supply those omitted intermediate steps. An original projection that fails has its original failure selection before R; the final branch can later use new application evidence without rewriting it.

## Conditional arguments and falsifiers

**Business noninterference.** In the model only `world.apply` increments Applications and consumes a pending original packet. No read action changes either field. Project two schedules onto the same sequence of independent original submissions and application services. Removing any query-only transition leaves that projection equal, by induction on the remaining steps. The endpoint argument uses the same coupling over business input bytes, key registry, receipts and counter. A concurrent independently delivered original can change the observed total between two queries.

**Binding and immutable knowledge.** Induct on the read stages. Only a returned exact-bound snapshot retained at the commit of a supported import sets ReconciliationSource. Historical unsuccessful interaction is assigned on its own original path and has no overwrite transition. A read-only resolver can retain and select true found evidence without an original import. A later absence or equivalent observation never removes retained application evidence. The independent decoder must separately check the concrete tuple, schema, authorization, original wire, ledger and provenance edges.

**Allowance and availability.** Request increments a logical debit once, fresh A increments the per-query expenditure, and death changes neither. No admission is enabled for a terminal query. Losing the first absent snapshot and later obtaining a found one is legal at the *second physical ordinal of the same logical request*. Retaining an absent snapshot requires a *new logical identity* to refresh. Spending both ordinals before entry can leave no endpoint read and no world evidence. The honest responsive positive requires a matching committed application visible when the query is serviced, a live entitled resolver or surviving evidence, and actual settlement, publication, forwarding and selection service. A missing response, unresolved application, closed reader, exhausted allowance or unserviced environment prevents that implication.

**Partial versus maximal histories.** Every row retains its exact enabled set, including independent world service. In particular, a state with a live accepted packet and prior Q can be locally idle while the world has an enabled application. The diagnostic Class is a projection. Read it with Held, Dead, owner loss, result/settlement/publication, resolver closure, and the actual edges. The per-profile sink list includes every row with no outgoing action even when useful continuation is unavailable. Maximal finite histories quantify over saturated choices in a declared profile. Stopping service early is permitted in the environment and entails no liveness theorem.

The reference suite finds historical falsifiers for post-Q nonapplication, definitive absence, read-as-import authority, arbitrary adapter success from a receipt, allowance reset on reopen, and lookup completion alone proving original discharge. Other controls cover the retained transport failure, a genuine counted ambiguity, a late resolver revocation and two ordered imports into one missing result. Bounds exclude rollback/Byzantine ledger identities, independent forged packets under the original key, arbitrary schedulers, unbounded responders, SQL failures, and a second live local writer after original Q. The SQLite accounting failures and corrupted histories must be attacked separately on the implementation. This qualification supplies no unrestricted refinement or crash equivalence theorem.
