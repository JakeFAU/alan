**Yes, for an exact operation under the controlled success protocol.** The decisive example starts with a successful issuing source and a genuinely missing captured result. Its separately authorized resolver obtains a unique receipt from the independent application ledger. Atomic import lets the original settle and its aggregate publish. The parent selects the original public issuance and the separately correlated receipt, checks both, and reaches `applied`. The original application count is one.
