## Reference domain

Use focused finite profiles, each grounded in one original operation and one declared responsive or withholding environment. Fix one namespace, source generation, immutable key/wire, reservation and one semantic original debit. Model original R, A, L and H separately; a packet can be accepted without applying, survive an owner loss and later receive world service. A successful original Q is eligible only after original revocation and the local drain. No query may discharge an original result at a pre-Q cut.

Each logical resolver request has a distinct key, one normal semantic debit and two durable physical opportunities. Each exposure can be lost before send or before local retention. Restrict principal profiles to at most two logical query identities (same resolver refresh, or two independently granted resolvers). At most one in-flight candidate per query/owner under the production Run restriction; two resolvers may have independently ordered responses. Small dedicated profiles distinguish one original-owner loss, one query-owner loss, and a two-loss exhaustion branch. For the principal adapter, at most one real application. For the raw non-idempotent ambiguity control permit two genuine original applications. Include an ordinary consumer with separate evidence and publication selections, and an independently enabled ordinary peer and revoker in the service profile. Split choices into local actions and optional environment/scheduler service. Enumerate all outgoing transitions within each declared profile before deduplication. Describe any projection compression and omissions at release.

Distinguish a structurally terminal run, quiescent environment that may later apply a packet, bounded allowance exhaustion, read/adopt refusal, transport unavailability, retained absence, explicit conflict, retained failed interaction, accountable intermediate state and actual useful continuation. State count is an outcome. The oracle and independent checker must exhibit/reject Q-implies-no-later-application, absence-as-final-negative, unauthorized adoption, arbitrary-policy success, reset allowance and query-only discharge. Each attack needs an executable transition or actual bad history and the violated condition.
