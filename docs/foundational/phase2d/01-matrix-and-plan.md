# Prospective matrix, source boundaries and implementation plan

The unit of experiment is one Store containing the owning caller and both resolver roots, plus an independently owned shared endpoint ledger. Never splice two one-operation decisions to manufacture the composition. A fresh activation cannot withdraw an accepted endpoint packet. A held worker can prevent a new physical admission.

## Source map

* `author/invocations.go`, `author/application.go`, `internal/executor/invocation_handoff.go`, `invocation.go` and `composition_binding.go` construct public programs, version and bind their template ports and install exact admitted permissions. Inspect validation and read-only replay for missing, colliding or swapped binding facts.
* `examples/owningtree/{tree,validate}.go` define the genuine T and the Series 1 parent guard. `examples/reconciliation/deployment.go` supplies the historical one-role negative. The new report is allowed to transport only actual authored values, with a saved request ID for its first witness.
* `internal/executor/{receipt_read,receipt_result,receipt_replay,reconciliation_profile}.go` bind and spend the physical read, retain proof and original in one transaction, settle an adopted original before its own query, and validate retained prefixes. A different admitted reader can see the result before that settlement.
* `internal/executor/{runner,dispatch,invocation_outcome}.go` distinguish first authorization, current physical admission, response handling, outcome delivery and consumer selection. For ACK service inspect all internal categories in `pendingDeliveries`, the actual `deliverOrdinary` call and the next ready Commit. Sorting alone does not establish uniqueness.
* `cmd/alan-resource` and `internal/fixture/ledger.go` provide durable independent application rows and serialized lookup snapshots. `adapters/receiptquery` fixes accepted protocol/policy and canonical bytes. `internal/boundary` and existing durable process tests provide cut and SIGKILL acknowledgments. SQLite readers are auditors and schedule observers only.

## Execution gates

1. Construct and attack the two-edge profile, immutable programs, public consumer and pre-query frontier. Review the contract, programs, port bindings, exact actual grants and both issuer ACK selections before freezing.
2. Implement the focused independently specified relation and enumerate bounded transitions, publish outgoing edge data, rank arguments, negative and mutating controls. Independently audit enabled transitions and frontier classification.
3. Run the branching families and acknowledged loss cuts. Save exact code, retained selections, journal, database snapshots, process identities, debits and opportunities. Have an independent decoder attack the actual role joins and accounting.
4. Freeze the entire executable tree. Run ordinary and race tests, a single coherent full root gate, focused historical gates, offline replay, format, vet and module verification in independent frozen worktrees. Keep old outputs and record pre/post source identities for every reported gate.
5. Compare the proposed relation to all counterexamples. Reconcile the two manuscript sources, review, build and visually examine the PDF. Index the qualified data and obtain independent whole-phase disposition before opening the draft PR.
