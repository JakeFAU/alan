## Source and method

The protected-entry argument uses the line of control in raw transport or adapter Execute, the held pre-call seam, the refused branch and, on the selected controlled route, the adapter's single original POST. The endpoints do not instrument arbitrary Execute internals. The R and Q tapes come from the causal orchestration and returns of the real APIs. H is bracketed by raw completion state, settlement events and Q. These fixtures have no general remote fence and expose no universal bound on waiting.

Only the explicit `finish-accepted` mode changes contexts at the validated request's pre-Apply wait and Apply. Defaults and drop-after-commit continue to use the HTTP request context through those steps. The ordinary Apply transaction, permissions, request keys and adapter ABI retain their existing semantics. The inherited authority fixture changed the unscoped after-permission expectation on both routes and the later revoked same-key contact count. A worker already admitted on either route can still make its first application after R.

New process and live checks read the SQLite backups, validate integrity, decode every retained table for the paired and replay comparisons, and join exact journal bytes to original keys, expected wire, world contact rows and receipts. Composition, public consumer and direct duplicate checks use retained Inspection table dumps and command transcripts where SQLite backups are absent. The direct same-key fixture counts physical contacts on an in-process test server. SQLite logical equality here includes raw BLOB values and row order and allows different SQLite image headers or free pages.

The checker does not call the ALAN reducer, runner, replay engine or Go harness. It imports the historical independent SQLite loader, joins for ordinary selections/effects and unchanged Phase 2A checks from `phase2a/tools/audit_observers.py` (SHA-256 `aa4a07be50bbe6fdce7aa315fef1826e43586a8c34005b3e1236514ce20414ac`) and `audit_withholding.py` (`43d021450b42d66a2a72cd6c19ee47613797e4d1efc3832e03e13ccec91c6d99`). It shares the project's retained formats and observes the same controlled execution, which limits independence. Seven deliberate in-memory corruptions were rejected, covering premature Q, spurious successful waiting, missing accepted ingress, altered wire, wrong death signal, reused owner and collapsed duplicate lifetime.
