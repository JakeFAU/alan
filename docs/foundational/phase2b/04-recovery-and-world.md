## Endpoint premise and replay

`alan-resource --response-mode finish-accepted` explicitly transfers an already decoded request's pre-apply wait and Apply to the endpoint process context. It still validates protocol and complete body before acknowledging ingress, and uses the ordinary SQLite application transaction. The response write can fail after a client dies. This is an opt-in world model. Default normal and drop-after-commit keep the original request-context behavior. The process-loss witness requires survival of an already accepted request, not an automatic retransmission or a second operation key. In the paired cuts no request is in transit at kill.

The same source-backed Run/replay helpers perform offline replay at both the cut and recovered state. They capture local and independent endpoint SQLite backups and exact ingress before and after replay. Equality of internal replay is evidence of historical consistency. Comparing world rows and journal bytes additionally tests absence of endpoint contact in these runs.

## Reading the packet

The command recorder binds selector, environment, complete output, source inputs and status. Child provenance names actual argv, cwd, executable SHA-256, embedded build info, selected effective environment and the root Go source-set hash. The race parent executes its own race-instrumented test binary in each child; the endpoint is separately built with the matching race setting. `*-process-start-PID.json` identifies a child and `*-process-PID.json` its normal exit. SIGKILL and kernel WaitStatus checks are in the command output's DURABLE record, linked to the causal cut's token. Endpoint readiness and any explicit endpoint restart are separately identified.

New process evidence names the case and cut followed by `-local.sqlite.gz`, `-world.sqlite.gz` and `-ingress.jsonl`. `*-U0.json`, `*-U1.json`, `*-known.json` and `*-delayed.json` include the controller transcript. U0 and U1 close-run comparisons occur respectively after the kill and after the fresh owner has obtained Q, made a full ordinary scheduling pass, observed Q again and closed.
