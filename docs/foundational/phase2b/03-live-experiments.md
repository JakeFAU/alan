The local tap records acknowledgments and releases, including the call to Q. It never runs an operation under the Store's mutex. On the inherited lifecycle hook it only appends a passive event and sends a buffered notification. A separate caller then reads the committed state. There is no hook inside Do or general Execute. The source placement of the held worker before the protected call plus the subsequent original POST brackets the tested entry. A refusal without a protected call also requires inspection of the dispatch branch. Zero endpoint ingress alone would be insufficient evidence.

Each live leaf saves an independent compressed SQLite backup of final local and world stores, an exact ingress file and machine-readable events plus held/closed/final inspections. The freeze ties these cases to one trusted owner, the controlled adapter with one internal POST, a bounded honest endpoint and finite local accounting. Dedicated parent, nested eligibility, capacity-one peers, multiplicity and ownership controls use separate harnesses.

After initial keyed application and lost response, a subsequent closed exposure leaves exactly one contact. The source, debit, retry and held-worker assertions remain applicable.
