# What a parent can select and a host can acknowledge

The standalone [consumer](../../../examples/revocation/consumer/main.go) opens a retained store, validates the supplied namespace, exact subject/generation and optional owning-scope target, and invokes the public wait. Its JSON success answers only the local-quiescence question. An eligible target returns the open-authority error. The CLI takes an explicit deadline. Opening while another live owner holds the file fails at the flock. Neither an inspection, an endpoint observation nor the host's Q is admitted to the authored parent.

|Case|Ordinary control and observations|Host or independent external observation|
|---|---|---|
|Responsive child|The parent selects its original successful invocation with a present guarded reply, then reports a historical application receipt.|The receipt is evidence under the controlled endpoint contract. The closed root can acknowledge Q.|
|Deliberately unsuccessful returned candidate|The child selects its normalized failure, and the parent selects failed/member_failed without a successful reply.|The host can inspect more detailed candidate evidence. A quiescence acknowledgment says handling ended locally.|
|No retained result|The parent remains at its original AwaitInvocation, having issued a request that could have applied. No authored unknown event is delivered.|The host report lists the missing operation. Its otherwise idle open root refuses Q.|
|Private Failure before admission|After reservation the test manually commits the child's next ordinary Failure while the dispatcher is held immediately before A. The parent later selects failed/member_failed with no reply.|Q for the terminal child can succeed even before the consideration resumes. The gate refuses it; the controlled endpoint has zero arrivals. The allowed reservation spends one debit and still lacks a result.|
|Private Failure after admission|The automatic scheduler commits the child's Failure, publishes it and lets the parent select the same failed envelope, while its admitted worker is held before physical call.|Release permits the original call and one application. Authentic late evidence is recorded/settled. The terminal child cannot consume it.|
|Nested successful freeze|An outer frame issues a child invocation and returns its own typed issuance marker. The original child can select the real effect result. The outer result publishes only after required descendant work.|The terminal frame's source Q can succeed while its owning scope still returns open. The successful unpublished freeze leaves the open child's reserved worker eligible.|
|Nested failed freeze|The outer frame commits Failure after child reservation but before child A. The outer parent can report the failed outcome while the child remains open at its unmatched receive.|Q for the effective owning scope succeeds. The original allowed reservation and its effect debit remain; the new gate refuses the child exposure without contact.|
|Successful issuing source|A resource root that issues an effect and immediately executes successful End is terminal locally. It has no remaining ordinary selection.|R before A leaves the root aggregation pending with `external_outcome`, one spent effect debit, and the original missing operation. Q for that revoked root can succeed. No progress premise here supplies the missing outcome.|

For the slow-effect control, the independent endpoint acknowledges the original request at ingress before application. Only then does the host admit inputs for the provisioned lifecycle operator and an ordinary peer. Run itself commits AbandonRun, completes the peer's ordinary work and preserves capacity one. A separate waiter observes an outstanding lifetime and is cancelled. After endpoint release the genuine original outcome is accounted and the independent delta-two effectful peer also completes. The test uses snapshots and acknowledgments to establish order. Its watchdog bounds a failed experiment. The public parent neither knows the remote counter nor directs this scheduler.

The resulting boundary has three parts. The original invocation supports conservative awareness that an effect may have applied. A failed envelope alone cannot resolve the application proposition. The parent can wait or take its already-authored next branch; another mutating action requires its own authority. A host's target-specific drain makes no such action eligible.
