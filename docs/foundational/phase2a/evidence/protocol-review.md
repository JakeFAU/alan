# Independent challenge before qualification

The reference author inspected the prospective experiment independently of the fixture authors. Initial verdict REVISE. Four required changes were implemented before qualification.

1. A first launch by a held worker and a second launch by a new Run are distinct. Add A5 with an unresolved raw idempotent original reservation, intervening source closure and a fresh Run.
2. A child selecting an unsuccessful correlated result differs from a child that fails through private control while an allowed effect lacks a result. Require the latter parent's actual selected envelope too.
3. U0 idempotent recovery creates the first application and receipt. U1 can return a receipt that already exists.
4. Ingress after closure alone cannot distinguish a first post-closure launch from a previously launched request arriving late. Require closed-state acknowledgment, release of a blocked pre-call worker, then arrival of its original request.
