## Independent check

From the repository root, run `python3 docs/foundational/phase2a/tools/audit_model.py`. The checker pins the profile inventory, initial state, environmental guards and actor identities independently. For every reached state it constructs all eligible labelled actions and their complete target states before reading that vertex's exported alternatives. It checks both directions, including absent and extra actions, exact targets, duplicate states, reachability, acyclicity, bounds implicit in the transition rules, and the reported counts and frontier categories. Pair actions are identified by actor index, owner-labelled action and local operation. An endpoint commit updates its actor's receipt ordinal and total from both actors' application counts. The checker uses the common serialization, profile and state vocabulary. It imports no Go model, driver, generator, runtime reducer or fixture verdict. I inspected the implementation and selected runtime guards separately. This is a second implementation of the finite relation, not blind replication of the vocabulary or an exhaustive check of all concrete interleavings. [Python checker](../tools/audit_model.py) · [Command, input identities and output](commands/model-independent.json.gz)

The checker accepted 1,300 states, 1,981 labelled edges and 85 graph sinks across 32 profiles. The two-actor graph accounted for 113 states, 180 edges and both orders of application. Five paired-cut profiles erase all volatile fields and retain equal local tuples in worlds with different application counts. From each reopen, every serviced maximum either selects the historical receipt on raw keyed recovery or retains the unresolved operation with zero added launches on the other routes. Eleven deliberate mutations were rejected, including removing a private fault or the only keyed recovery, removing one of two enabled source emissions, substituting a generation, substituting worker or peer ownership, changing a shared counter total, counting a reservation as a launch, inferring nonapplication from loss, leaking world state to the parent, and adding a retry to an old adapter reservation.
