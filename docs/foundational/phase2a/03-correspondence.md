# Bounded reference and source correspondence

## Declared domain before exploration

One immutable operation O belongs to the source at namespace N, logical generation 1, revision 1, fixed sequence and ordinal, with a fixed bounded increment and honest grant. All transition labels have an owner and a subject operation. A registered member can incur one effect debit. A scenario may replace the grant with a refusal or set the member effect limit to zero. One externally enabled peer may finish one independent pure step. When present the parent has already issued and admitted its original invocation, is waiting on that handle, and its child is ready to emit. Source and ancestor are distinct identities. A closure-capable scenario has one already authorized lifecycle operator and may take one matched open-to-closed or retirement decision after emission. The graph includes its refusal to schedule as a finite prefix; service below concerns eligible work, not a requirement that a human cancel.

Use separate finite graphs for the two routes with unscoped / registered-member closure, grants and allowances, U0/U1 and known crash recovery, two endpoint profiles, and parent probes. The input manifest is the profile header of each export. The core owner interleaving starts immediately before the selected effect emission; setup, peer placement, and lifecycle intent/authorization are fixed prefixes. Execution capacity is one effect worker. A normal profile contains one Run. A recovery profile permits one kill/reopen or one deliberate second Run after a response loss, with no third Run. A crash is enabled only at the held pre-launch worker, the validated volatile response, after recording and before settlement, or after settlement and before selection. No crash during an in-flight packet is quantified. Permit at most one source/ancestor lifecycle transition and one endpoint reply mode per profile. The parent profile either guards a selected result or takes a private failure after emission without selecting an effect. For genuine connection loss the endpoint may have already committed or may have rejected the connection before application. The negative pre-application alternative supports an information comparison, independent of fixture testimony. The executable enumerator does not ingest runtime histories, production packages, expected verdicts, or generated fixtures.

The extra two-operation comparator fixes source delta 1 with a deliberately unretained unknown candidate, and a responsive peer with delta 2, each with its own key. Both orders of endpoint commitment are possible in the reference. The comparison retains the order and the counter value at each commit. Its service boundary is completion of the second operation and truthful unresolved status of the first. This is a finite comparator, not equivalence of peers under all shared resource policies. The original one-step peer in the single-operation profiles represents an independently enabled pure step. It is not a substitute for this effectful comparison.

## Projections, comparisons and limits

Program observation is its own original handle, selected output/disposition and deterministic control; the parent has its own invocation handle, selected envelope and derived local decision. The issued request and the known child justify “may have applied” while still waiting. A failed/member_failed envelope can be selected both after a consumed unsuccessful result and after private failure without any retained result. Its payload does not disclose which world obtained. The host projection includes the abstract retained local tuple (the public Inspect table view) and the allowed-but-missing-result indicator (Run report). The oracle additionally sees worker calls, fresh/reused process, and the independent endpoint journals. Exact source/endpoint IDs, bytes, raw reason, schema, signedness, revision and preparation are fixed common parameters in each single-operation graph; other operation identities are refused. The model's receipt token quotients its opaque process ID and numeric fields. It cannot verify byte equality of two real receipts, and does not assert two independently started endpoints generate identical bytes. The record audit must compare actual bytes for each same-key duplicate.

At U0 and U1 take exactly the common emit, permission, reservation and worker-entry prefix, without intervening peer work. U0 kills immediately. U1 adds the applicable Execute/Do, ingress, application and validated returned receipt, then kills. Those extra edges do not write the local store. Both histories lose all volatile values, so the complete abstract Local tuple, projected parent and retained permission epoch match after death. The oracle differs by an application and the associated physical counts. Opening advances the same activation on both sides; later permitted endpoint evidence may legitimately differ. This argument relies on the explicit common prefix and on the guards' read sets. General state equality of this compressed tuple does not imply equivalence of arbitrary concrete SQLite histories.

For responsive keyed raw recovery, U0's new launch first applies once and U1's second launch recovers the already bound receipt. For each non-keyed raw or old adapter reservation, suppressing repetition leaves a genuine honest boundary. Given only those paired local facts, any local policy making a decisive nonapplication or application claim at the cut is wrong on one branch. Retrying the same non-idempotent operation can duplicate U1. Never retrying loses completion on U0. This argument quantifies over the declared two worlds and no decisive reconciliation observation; it does not constrain a different endpoint contract.

Every exported row contains all owner-labelled alternatives generated from the original state *before* successor interning, including multiple outgoing alternatives from the same source. State comparison includes world and counts, independently of equality at the recovering observer. The command additionally checks acyclicity on individual graphs. No exploration depth/queue cap exists. All paths are finite in the declared event quota. At quiescence a selected responsive profile must have serviced its effect. Pending no-result rows with zero approved retry are allowed, while skipping the eligible keyed retry fails the checker. A single-slot peer cannot be withheld to manufacture the verdict. Repeated saved lookups, repeated inspection, pure deterministic valid Prepare, idempotent accounting of an unchanged settled row and polling are silent here. They cannot update any declared observation, grant a fresh second Run, or create a new reservation. Unbounded stutter must not starve an eligible nonstutter; no path formed only by polling counts as a serviced maximum.

The transition relation allows independently eligible choices in a single-owner Store plus worker/environment interleaving; it is not a compiler for the deterministic automatic Run scheduler. For example, a public permission sample may be driven before a private failure or closure. Only the process traces can qualify a particular automatic order. The reference abstracts register moves and deterministic branch plumbing within the declared projection. It excludes hostile endpoints, unbounded crash/retry, concurrent owners, malformed prepared config, operation budget exhaustion outside the designated refusal, root retirement following successful publication and voluntary runner-context cancellation from crash exploration. Runner-context cancellation has detached bounded accounting and is tested separately. The two-key and competing-result controls are finite direct endpoint/record experiments, not enabled runtime recovery actions. One revision-scoped deployment grant can permit both generations. Each original operation still requires its own first permission decision and reservation. There is no assumed public method for injecting a conflicting receipt or initiating automatic adapter resubmission.

## Executed checks

The export contains 32 profile graphs, 1,300 states, 1,981 labelled edges and 85 vertices without an outgoing action. Of these, the effectful single-slot comparison contributes 113 states, 180 edges and two terminal orders. Every interval is bounded by the profile; the exporter uses no search cutoff. “Completed” in the export's coarse frontier category includes terminal control after a selected result. Read Program to distinguish actual success, guarded failure, and cancellation after selection.

The tests reject a launch attributed to a held worker, application before ingress, an action with the wrong operation or owner, suppressed eligible same-key recovery, an oracle-dependent parent policy, reusing a different generation as the original operation, overwriting a prior result and interpreting normalized failure as evidence of nonapplication. They also check post-closure launch as a witness against L. The initial scaffolding compile failure is retained separately; that RED did not test the launch theorem. Model state counts and passing tests are finite evidence, not a universal recovery proof. Names and numeric fields are interpreted through the projection above. The raw fixtures use delta five, while the adapter source uses delta one. The single-operation graph counts applications and uses a receipt token without its numeric total. Concrete immutable identities, request bytes and the retained permission epoch are compared directly within each crash pair; mapping them to the symbolic model identifiers does not replace that comparison. The source activation advances on reopen while the request and first permission retain their original epoch. The authority graph's single-contact endpoint-mode choice is observationally immaterial within its one-launch bound, although the actual authority fixtures use the idempotent service.
