# Finite open composition account

Can sibling authorization, shared admission and reply service interleave in a way that prevents the frozen selection policy or changes a genuine diagnostic? The qualification below covers a **finite abstraction under the positive component and deployment premises**. Its use for Store executions depends on the separate actual leaf, constructor, frame and service arguments. In particular this model cannot establish absence of faults in a new retained program. Its author read the frozen contract, campaign plan and historical code/interpretations before construction and derived the model without reading the new constructor or runtime campaign results. ## Configurations and observations

The graph starts at O's ready initial Invoke with empty spent set and zero dynamic debit. Each role path identifies a **fresh original call** through its actual parent, independently of data, template or branch completion order. The address also identifies its unique request, result and entry member. A role's `send` uses its own captured reply key. Outcome selection uses its parent's run and that specific original call. Fixed generation, original template/obligation and provenance are implicit in each indexed request/outcome. Paths are proof names for a legal injective binding; their characters never occur as transmitted identity data. Literal input payloads are printed in field order id,value,mode. S receives only id,value, h receives id,value,answer. A semicolon in a normalized product separates successive *static* leaf roles. The named roles in a normalized report index the schema field positions. For example `O/tree/left=1,answer,[1,1]` denotes that role's id, classification and one answer record. The path is absent on the wire. Empty payload denotes an absent response. Reasons uniquely determine public status in this domain (only member_succeeded is successful). Member End status is retained separately; in particular successful End without reply gives failed/missing_reply. O's decision separately commits before its own End and root publication.

The original kernel and component results fix the productive branch for a request. S always replies (id,0). B commits and selects h even when its own mode is pending/fail/absent. J commits e then S, selects S then e. It derives its report from original selected candidate evidence in the model. Fork and Relay concatenate/copy the *selected* child reports for a positive completion. On an unpublished child the parent stops at its first missing selection; construction of every child process has already occurred at the semantic level so this never stops a sibling's own enabled service. All children still need an actual parent commit, first authorization and admission before their member can run. One root ledger counts each admission bit, including all sibling and helper charges. I/R and depth adequacy, stable open bindings, capacity one and no interfering work outside the term are premises. There is no independent reservation slot.

The minimal Fork enumerates 4 × 16 × 16 configurations with literal values. Each three-leaf association enumerates 8 assignments × 64 ordered modes at (id,value)=(1,0),(1,1),(2,0). Each relay placement enumerates 4 × 16 mode/assignment combinations at (1,0),(1,1). For these other placements the control/eligibility argument extends to per-leaf numeric choices only because the local computations copy that leaf's id, test equality to it, test its own binary value and complement, inspect fixed-size cardinalities, and prefix/copy its fields. Each literal substitution preserves the local truth tests and updates the answer value explicitly. No cross-role id/value comparison, value-dependent admission, identity equality on application values or cross-role indexing is allowed. Value changes can change private PC paths/counts. Only their terminating boundary action is identified here. The reported counts use the actual representatives in the census.

## Exact symbolic graph

For each fixed case, events are original one-shot occurrences with a role, action kind, issuing owner, ordered transaction word and a conjunction of predecessor events. The machine state is the **downset** of events performed. At D, every unperformed event e whose predecessors are all in D has one outgoing edge to D union {e}. This definition includes every sibling placement between two distinct transactions. There is no placement inside an atomic word. It does not enumerate all linearizations as distinct state objects. Ordered histories remain paths; a downset is not an authoritative Store snapshot.

An Invoke commit is owned by the parent. A fresh first decision reads its source, and later current admission checks the source/scope, allowed binding and capacity before atomically giving the accepted admission/member/request/debit. Ordering of the abstract facts inside that word follows admission record, singleton creation, request insertion and charge placement. Send and its first authorization and disposition are three separate events. End/freeze may precede first permission, intervene before recording or follow recording. Publication requires End and every applicable reply disposition. Its publication fact, outcome fact and outcome delivery to the caller share one action. The later Await consumes once. These rules retain the distinction between occurrence, first permission, actual service and selection. The role's original typed request and outcome identify all those actions. Root has neither an outward port nor a dynamic charge. **Private cuts.** Erase intermediate local scalar tests, sets, bounded loop steps and cursor positions between retained boundary instructions. Keep every original Invoke/Send commit, request/outcome consumption, transition to the genuine unmatched entry receive, End/freeze, outer decision and each Store protocol action. No erased computation commits an operation, changes scope, releases service capacity, consumes input, or reads a sibling's mutable state. Displace a service at a private cut to the same interval between its two bracketing boundary actions, retaining its order relative to other service and other roles. Conversely schedule the finite private prefix immediately before the boundary that needs it, with other roles paused for those finitely many steps. For a post-End reply first decision keep the actual End on the correct side. Numeric source sequences may change when such a cut moves. The positive actual-machine proofs must exclude operand faults and internal infinite loops and derive genuine wait positions; otherwise neither displacement nor service preservation follows. This is a summary of the named deterministic open occurrences only. It is not the earlier nondeterministic K1 reference with optional private choices and closure.

**Outgoing equality before deduplication.** The recursive generator constructs a submitting run's causal script and forks independent service chains. The oracle starts from the role inventory, derives each serial instruction stream, computes child packets from per-role specification, and superimposes local Store guards. It consumes no submitted edges. They share role enumeration, typed input rendering, action-key and data encoding and basic set operations. Neither imports runtime, compiler or new constructors. Before counting or consulting a repeated-matrix cache, check identical unique alphabets, acyclicity, action owner, ordered words, prestate snapshot source, resulting event bit and strict transitive predecessor sets. For any event the cone of strict predecessors is its least enabling downset. Every larger downset omitting that event enables it exactly if it contains this cone. Thus equal cones and labels test outgoing equality on **every prestate**, and a different cone or event supplies an explicit differing cut. The initial cut is empty. Every downset is reachable by any topological ordering of its members. This proof uses the simple conjunctive event language; an arbitrary labelled transition system would require additional checks. **Counting.** For a disconnected comparability graph the downset lattice is a Cartesian product. For factors (S1,E1),(S2,E2) it has S1×S2 states and E1×S2 + S1×E2 edges. Otherwise partition on a pivot v. Ideals excluding v are all ideals of P minus the closed upset of v. Ideals including v have the closed downset of v fixed and all ideals of the remainder. A cover crossing this partition adds exactly v, so each corresponds bijectively to an ideal of elements incomparable to v with all strict predecessors of v fixed. Add the two state counts; add both internal edge counts and this last count for edges. The empty poset contributes (1,0). Recursion strictly decreases, with exact-mask memoization and checked uint64 arithmetic. The implementation accepts at most 256 events per case; the largest here has 143. It has no schedule/step cutoff. The recurrence calculates each complete reachable graph's cardinalities without materializing billions of states. A separate worklist using direct guards materializes all 97,360 states/421,217 covers of BB answer/answer, and all 17,048 states/66,593 covers of AB pending/absent at duplicated data. Both match the recurrence, yield exactly one maximum and expose each captured reply first authorization both before and after sender End. **Progress.** Remaining rank is |P|−|D|. A productive edge decreases it by one, ruling out productive cycles. Every proper downset has an enabled minimal missing event. Its lower set stays performed, and the event stays enabled until served. Under the actual private/lifetime/eligibility premises an infinite erased suffix cannot consist of eligible finite private computation or continuously unserved prerequisites. Stuttering at a proper downset forever would withhold some continuously eligible work. This leaves one serviced maximum (full P). The maximum reader checks each owned descendant occurrence lies strictly before ancestor publication, including failed ancestors, and reconstructs for each open member the first missing original select or designated second entry. A later delivered-unselected sibling is recorded. The independently derived frontier/decision and the reconstructed maximum must match in every case. Faults, exhausted allowances, malformed graphs, interrupted runs and withheld service are outside this classification. [Maximum checks](../../../../research/owningtree/census_test.go)
