# Typed constructors and emitted instructions

The question here is whether each generated parent, given authentic selected child outcomes, implements the frozen local policy. The constructor argument is by inspection of a restricted set of lowering cases and by induction on the number of role blocks. The separate Store bridge supplies authentication, admission, settlement, binding and service. Shape checks alone cannot establish a child's semantics.

## Type and identity

`Leaf` compares the candidate's retained request/response digests with the historical protocol. It obtains S from the sequential builder with a fixed legal construction input, discards that provision and passes the original candidate and S to N's unchanged `NewJoin`. No extra peer or caller from the construction input enters the resulting deployment. An initial negative test admitted a candidate whose request mode enum contained only answer: the existing type checker permitted overlapping string enums. The new factory rejects that input before constructing J. The regression test exercises this distinction without changing the compiler or the original J.

For any leaf path p, the request fields are p followed by id, value and mode. Its report fields are p followed by id, classification and answers. N fixes all six field types, including the exact answer element schema and the 192-byte, one-item bound. A Relay preserves the paths; a Fork prepends l_ or r_. These prefixes have equal length and unequal first symbols. Within a child the induction hypothesis gives distinct paths. Neither input fields, output fields nor register families from different roles can coincide. Constructor `leafPaths` enumerates id fields, requires each path to consist of whole binary branch prefixes, requires both children of every internal prefix and disallows any leaf at an internal prefix. It independently rebuilds both expected closed records and compares the canonical schema IDs. The frozen domains of id and value are checked on provisioning and mode is schema-validated. The term builder never sees a request value. [Construction](../../../../examples/owningtree/tree.go)

The template constructors retain one entry member with an empty open initializer at PC zero, one caller port and just the direct child IDs in the descriptor catalogue. Equal child IDs share a catalogue entry. They still have distinct local declaration names and committed occurrences. The public authoring API retains exact programs, metadata and transitive dependencies in the bundle. In particular the generator adds no initial child runs or per-occurrence host adapter. O uses the identical role decoder with a single tree declaration, provisioned as the only fixed root.

## Instruction correspondence

Write n for the number of leaf roles in one immediate child. The following describes the unbound canonical bytecode. The signed displacements used by the checker are relative to the current instruction. Dynamic placement resolves only declared message endpoint operands. It leaves invocation operands, data and comparison literals unchanged. [Bytecode checker](../../../../examples/owningtree/lowering_test.go) · [Placement](../../../../internal/executor/composition_binding.go)

1. A member starts with ordinary-message Receive from the declared caller on work, binding every request field to the same register name. O starts with exactly those registers initialized. Invoke emits an invocation intent with literal child template, generation one, declaration as obligation and the child's request field projections. Its destination is the original operation register. The entire ordered invoke slice is concatenated before the selection slice. `Reduce` derives an operation from run, generation, commit sequence and ordinal. Two fork invocations have different commit sequences and destinations, even with equal data and templates. No later instruction writes either destination.
2. Global tree_valid and tree_answer are set true once. For each immediate child, the next receive matches invocation, runtime-invocation provenance, literal template, generation one, local declaration and that child's saved operation. The reducer checks the destination run and every selector before it accepts a payload. It binds status, reason and response_present to child-specific registers. Response fields go to report_ followed by their fully qualified field names. The Store's original binding supplies authenticity in addition to selector equality. On absence the reducer **deletes** optional destinations. The resulting private block first initializes the child answer bit, then branches on the presence bit. Its false target is 35n+17 PCs after the branch and only sets tree_valid false. Both arms rejoin before the next selection or the final policy.
3. A present envelope executes n consecutive 35-PC role blocks in lexical path order. Relative to the start of one block, 0–2 compare the selected report id to its own request id and invalidate on mismatch. At 3–6 both branches define expected as the complement of the legal input bit. At 7, seen becomes false. PCs 8–20 traverse precisely the selected answers value. Foreach snapshots the typed list, next binds id/value on an actual row, and loop returns to next. Exhaustion at next jumps to 21 and removes the cursor without executing the body. The body tests uniqueness, marks seen and tests row id against the same request id and row value against expected. Every failed test clears tree_valid. Scratch row fields are only read after a successful next. This remains true when retained scratch fields from an earlier path still exist. At 21–34 an answer requires seen true. Any other tag clears the child answer bit, requires seen false, and is accepted only if it is candidate_failed or candidate_missing_reply. No path reads requested mode after forwarding. No path overwrites a selected report, the request or a handle.
4. Induct on the number of processed roles in this present child. The child answer bit remains true iff all tags so far were answer. Starting with the previous global validity, tree_valid is conjoined with each fully checked role predicate. The next block reinitializes seen and expected. Its path names are disjoint from prior selected destinations. After n roles the envelope tail requires succeeded/member_succeeded if the child answer bit is true and failed/member_failed otherwise. The latter also clears tree_answer. Neither global bit can become true again. Invalid evidence, including a wrong status or reason, therefore cannot acquire eligibility for the final Send, irrespective of later sibling results. An authentic missing reply or absent failure follows the presence-false edge regardless of status. Neither is a diagnosis with a fabricated product.
5. After all required receives, the final validity branch selects the sole normal Send followed by the tree_answer branch, or the no-Send failure block. The normal Send maps each parent wire field to its selected report register, with original list values, tags and literal ids intact. On this branch every selected envelope was present and normal, so every Send operand is defined. Sender success occurs iff every role answered, while a diagnosed sender fails after its Send. O substitutes no Send, records decision answer, diagnosed or invalid_tree_outcome and Ends accordingly. O's selected product fields remain inspectable separately from decision. There are no earlier End instructions or jumps over a required Await. Thus the generator itself keeps an unresolved parent open. Even an invalid left outcome must wait for the original right outcome. A later sibling's outcome already published cannot match the waiting left receive.

These counts follow from `author.compiler.expand` and `step`. A set, Send, Invoke, Receive, Await or End emits one corresponding instruction. Each nonterminal IfEqual emits one branch, its then block, a forward jump to the join and its else block. An empty then arm has a fall-through join jump as well. A then arm ending on every path omits the jump (`reachesBoundary`). A comparison that invalidates has a three-PC expansion. ForEach contributes foreach, next, the lowered body, loop and its exit address. This family contains no labels, gotos, appends, nested lists or nested loops in the new parents. Concatenating one more 35-PC block shifts the present-false jump and subsequent absolute PCs by 35, and leaves every internal relative target in earlier and later blocks unchanged. The selection block for n roles has length 35n+20, including its receive, initializer and absent arm. Thus the correspondence extends to every recursively constructible, representable product in this family. It requires successful schema/type/size validation and the environment and operational-byte premises. Each accessible reference is defined by input, preceding set, selected response on presence, or populated row on next. A forged selector, invalid wire record, exhausted bound or private reduction fault supplies no serviced-pending certificate. The executable checker instantiates the interval and both exit alternatives against actual decoded PCs, comparing all executed kinds, role-relative operands, original bindings, branch targets, list bounds, aggregate projection and terminal statuses. It compares the entire instruction sequence, including every invalid path, and checks the template/declaration identities. It exercises both association directions and relays on aggregates for AA, AB, BA and BB. This is a finite check of the pattern argument, not an independent implementation of the whole reducer. Its disassembler relies on the inspected interpreter's meanings for these instruction fields, canonical public artifacts and schema checks. It does not establish Store authenticity or a general compiler theorem.

## Reproducible standalone execution

The independent Go module imports only public packages. Its parser fixes the term and its budget/depth before binding the input array in leaf order. The frozen example uses fork(relay(A),fork(B,B)), three equal application IDs of 2 and, in order, (1,fail), (0,absent), (1,answer). The representative executable's SHA-256 is `56e5539d0e6eefe8d1959be43f6feb71b7952c179c297398b01618bad62438d8`. All three command records include flags, executable, cwd, environment, source hashes, exit status, and raw output. The physical ledger charged 14 invocations and 14 created runs; the common allowance was 15. The root selected the failed present product, retained candidate_failed, candidate_missing_reply and answer, including its (2,0) row, and ended failed with decision diagnosed. The Store reported quiescence with zero open runs, rejected admissions, pending deliveries or unresolved intents. It used 374 steps and 40 dispatches at capacity one against pre-run watchdogs of 2593 and 46. For the positive family each program costs at most its instruction count plus its number of singleton foreach headers, since only next can repeat once per cursor. Multiply the largest such cost by b(T)+1 to cover all potential member occurrences plus O. Each accepted slot needs at most three dispatches for admission, bound reply and outcome delivery. The runner uses one spare unit on each bound. These are finite adequacy bounds for this closed grammar; arbitrary adversarial programs need independent accounting.
