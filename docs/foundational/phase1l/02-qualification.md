## Limits and remaining question

Preserved reference-checker and raw-validator failures are detailed in
[03-review.md](03-review.md); they were corrected with RED/GREEN evidence and
independent rereview. They are evidence-validation defects, not observed runtime
substitution counterexamples. No production/compiler/runtime repair was needed.
Historical I/J/K static-peer failures and the J2 construction obstruction remain
intact: C_inv deliberately changes topology and uses invocation outcomes.

The broad default 10m command remains a recorded timeout. Its completed cases plus
the documented 60m targeted adaptive follow-up supply combined default coverage;
there is no single-command suite-success claim. Exact disposition is in the
runbook. This finite single-host result leaves arbitrary context grammars,
general compiler correctness, effectful/distributed recovery and universal
equivalence open. The next question is whether a separately stated larger
context class preserves this guarantee under explicit shared-resource and
scheduler assumptions. The [machine evidence index](evidence/index.json) links
source identities, evidence layers and decisive retained record selectors.
