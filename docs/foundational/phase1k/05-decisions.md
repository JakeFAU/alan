# Phase 1K decisions and remaining questions

1. **Keep three execution domains distinct.** Independent model reachability,
   supported public-driver reachability and unchanged automatic scheduling require
   separate evidence. One internal delivery followed by one local commit is not
   a general drain-all-deliveries barrier. A sole-pending-report exclusion remains
   conditional on the exact retained queue and readiness state.
2. **Preserve the original message and first disposition.** A later allowed or
   refused authorization is a reuse of that first record. Receiver openness,
   identity, route and schema remain admission conditions. Dispatch acknowledgment
   can record a refusal and cannot establish receiver consumption.
3. **Freeze one ACK candidate and preserve its failure.** The finite J2 product
   admits ACK-refusal pending maxima. No ACK-of-ACK or retry protocol was added.
   Its exact authored peer then failed the static handle/string comparison; the
   full attempt and compiler diagnostic remain evidence.
4. **Honor the construction boundary.** A collection conversion would change the
   frozen prefix. Correlation was not weakened, compiler output was not rewritten,
   and production semantics were not changed. Available roots and original
   templates support partial mapping only; full J2 runtime correspondence is
   unresolved. Returning an empty Provision on construction failure prevents a
   caller from running J1 under the attempted J2 name.
5. **Separate constructor and runtime access.** The external raw terminal probe
   succeeded using the existing public runtime. The missing ordinary author
   terminal-wait constructor therefore does not establish an API-wide absence.
   The host's authorization result and a retained terminal observation are also
   different facts.
6. **Make the refused crash cut a genuine retry.** Independent review rejected an
   initial cut with no prior admission. The approved cut retains refused
   authorization, refused original transport admission and dispatch acknowledgment
   before kill, then retries the same identities after reopening.
7. **Reject causal cycles without inventing global time.** Independent review
   found two oracle false negatives. The corrected peer-sequence checks preserve
   both counterexamples and accept honest incomplete/reordered traces. They add
   necessary causal edges for this one protocol, not a global actor ordering.

8. **Validate every decoded prefix.** Runtime review found that a lookup miss
   could bypass the truth checker for a wrong target or obligation. Both mutations
   and a genuine pre-report control are retained. The narrow correction passed
   complete normal/race coverage on the same revised source and independent
   scoped rereview approved the correction.

9. **Make selected decoder cases self-contained.** Final review found that a
   single filtered attack skipped sibling fixture setup. Lazy genuine fixture
   construction fixes that reproduction without skipping attacks or weakening
   their checks. Latest decoder normal/race results are recorded separately from
   the earlier complete runtime campaign.

## Next semantic question

The handoff is now concrete: a retained first allowed authorization can outlive
its source under the stated destination assumptions. The ordinary authoring
surface does not expose that authorization fact. An ordinary ACK introduces its
own source-lifetime obligation in the independent model, while the exact selected
construction additionally fails handle/string comparison. The raw runtime can
already admit authentic terminal observations.

The next question is which precise authoring representation and completion fact
can support a finite protocol argument: exact operation-identity correlation and
a matching authentic successful terminal outcome both need explicit treatment.
If successful peer End is reachable only after consuming the required ACK, its
matching authentic terminal observation could witness that consumption. This
requires a new complete construction and qualification; a cancelled or unrelated
terminal observation cannot substitute. No such third protocol or new constructor
was added in this increment.

Complete J2 artifact/runtime correspondence, arbitrary-context scheduler claims,
general compiler correctness and distributed/effectful recovery remain open.
The automatic exclusion applies only to the verified sole-pending-report boundary.
