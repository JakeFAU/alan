## What the handle probe establishes

The [prediction](evidence/probe-plan.md) preceded the executions. The same public parent artifact, with empty application input, invoked and selected an original helper at depth one in each store. It saved its emitted handle through a bounded string collection, awaited the original helper and compared the extracted string to the same literal. The helper returned the same integer 7 in both executions.

## What would settle the original question

Define which initial values and operations an arbitrary original private machine receives when its owned binding changes, then show all its reachable choices, updates and required eligibility transport under the original name domain. An alternative could show that a coherent original execution already realizes every needed literal-valued operand along each translated execution. A negative would need a specific admitted X, original W and Progress on all sixteen inputs, and a legal translated violation with those same semantics. The arithmetic of shifted depth and prior spending does not decide among these possibilities. Phase 1O’s stronger relation-existence question ARG-2 also remains open.
