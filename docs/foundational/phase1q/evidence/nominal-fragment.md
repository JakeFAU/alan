# A sufficient private operand discipline

Fix an original P instance and one proposed placement of the same candidate. The following additional source restriction, `Nom`, answers the private-instruction part of relocation. It can be checked on finite instruction text, initializer and operand declarations. Applying it to an implementation also requires identifying its actual initializer, instructions and binding/limit rules with these primitives. Original `A_op` supplies no such typing judgment.

**Operands.** Give each local register one sort throughout its lifetime. Data terms are literal integers, booleans, strings and finite declared records/lists of data, defined data registers, projections, and fixed pure operations on these (e.g. integer offset, same-sort equality). Fix the operations by syntax and their literal semantics, including definedness. No arbitrary host callback is a primitive. Use separate optional handle registers indexed by original child declaration. Handle terms are defined handle registers. The only handle operations are copy, same-sort equality, and use as the operation operand of an Await for that declaration. An actual Invoke writes the newly committed handle. No literal, cast, text encoding, ordering, hashing, collection slot, payload or data binding can produce or inspect a handle representation. Run IDs, sequence, catalogue IDs, root/caller identities, and grant/depth/limit fields have no private operands. Bound ports and template references are instruction descriptors resolved by the kernel.

**Instructions and initialization.** Start each member at a fixed PC with fixed literal defaults, empty handle registers and the same definedness mask. Entry Receive binds only the declared original request data. Authenticated Await binds declared status, reason, presence and available response fields, clearing absent bindings. Allow typed assignment, fixed jumps, guarded branches on the preceding tests, declared finite alternatives, Invoke with data payload, Send on the original bound reply port, Receive/Await and End. Alternatives enumerate the same syntactic successors whenever their guards hold. All private control changes, including any silent alternative, count as actual steps. Reject constructors varying defaults by placement, instructions fetching ambient state, and untyped register reuse.

**Primitive-step argument.** Pair equal PCs, control choices, definedness and literal data. Pair live handle values by original commit occurrence, with a single injective correspondence through the history including all aliases. Start from the legally covered P binding, using equal literal initializers at the new entry. Structural induction on a data term gives the same value or undefinedness. Copy preserves the handle correspondence. Injectivity preserves and reflects equality even with aliases. Hence at each PC the same private branches are enabled and produce paired successors. Invoke evaluates equal payloads. At a paired lawful commitment its fresh handle extends the correspondence consistently, since distinct original commits have distinct operation identities in each history. Receive/Await select only actual matched deliveries, compare the genuine structural descriptors inside each frame, and install equal literal fields. Reply and End select identical data/status. These cases induct over each actual instruction in either direction between corresponding protocol cuts, including the first step. The proof uses no reference match at the new placement.

**What the frame must establish separately.** Pair the old root resource anchor with the new root and J's old immediate caller with the actual innermost relay. Their old alias cannot be an input to private equality. Check fresh actual entry/return routes, parent and root catalogues, schemas, grants, current generations/revisions, source and ancestor lifetimes. Check first authorization independently of current admission and the actual bound-reply exception after End. All relay charges precede J. Shifting depth and cap by k and subtracting k prior charges relative to the P product preserves the inner numerical comparisons. Only S acceptance projects to q. Require both encodings and every relevant pre/post state to fit the two frames’ operational bounds, including key lengths and positive representable sequence, with adequate dispatch/activation service. A longer key alone can otherwise disable a step. These are instance checks outside the operand typing.

Outer waits cannot change a private branch operand. A receive still needs its declared Await/Receive and retained matching observation; verify persistent eligibility of the actual delivery prerequisites, initial entry, q and delayed selection as in P's service argument. Then a continuously enabled private action stays realizable across erased outside steps. An infinite projected execution retains every private step; a finite projection cannot hide a persistently enabled action behind an infinite erased suffix under the stated service. Mode termination or designated pending still requires original Progress. This private lemma neither establishes the general kernel/caller projection by itself nor discharges Progress.
