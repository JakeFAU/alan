## Authority/minimality checks supported by source and retained tests

- The only grant writer is committed lifecycle processing: DecideLifecycle reloads the exact request, checks source authorization, then uses the authority policy instead of broad lifecycleGrant. Immutable results and existing composition lifecycle facts retain the decision. Issuance checks current source openness/revision, complete original permission membership, exact static holder/root, recipient identity/root/revision, and authentic committed message origin. A grant cannot itself be a root.
- `rootReason` compares a whole Permission value from immutable composition_permissions, with holder/root coordinates kept distinct. `evaluateEffectAuthority` adds exact action equality, explicit own/delegated path selection, accepted Delegate result identity, recipient revision, exact service ID, original accepted message admission and immediately preceding selected observation. There is no ambient or fallback lookup, and a grant-shaped result/message cannot become a lifecycle grant.
- First effect decisions remain immutable. Rechecks reload the same selected witness and the original allowed reservation and serving-root effect charge. Admission records are primary facts in the existing shared total order, with contiguous per-original ordinals, historical prefix reconstruction, attempt digest, actual activation evidence, and refusal retention. They neither allocate another debit nor refund the original. An allowed record is an opportunity, not evidence of contact or a resumable permission.
- Normal delegator completion is deliberately distinct from root revocation/retirement, as the contract specifies. The retained completion-consent test and monotone exact-root revocation tests probe that distinction. Generic adapters retain the old allowed/no-result unknown state; no new automatic retry branch was added. External repeats retain the original immutable endpoint key/request and obtain a fresh gate.
- The profile rejects unsupported feature combinations and requires two static generation-one members. Formats 13/14 reuse composition tables and extend only the fact kind. Conflict promotion is 13→14; feature predicates use explicit versions rather than numeric ordering. The independent reader hole above prevents approving feature isolation yet.
- The new admission policy is shared by replay and typed inspection. That sharing is explicit and is not an independent research authority oracle. The later independent model/checker must still challenge it.
