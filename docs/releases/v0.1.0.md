# v0.1.0 release notes (draft)

ALAN runs bounded, single-host Go agents with local SQLite ownership. A program can commit an effect request, exit and later consume a result in a new process. Inspection and replay read retained evidence offline. The [ticket-routing quickstart](../../README.md#build-your-own-durable-agent) installs the runtime package and supplies a credential-free application with its own adapter.

- Creation validates the initial computation before reserving a destination. Correct invalid provisioning and retry. Preserve an interrupted or ambiguously committed destination for recovery.
- The public Store methods, runner options and error identities are discoverable with `go doc`. Hosts can identify a missing capability, malformed adapter output and an ineligible continuation programmatically. Live provider metadata must contain valid optional usage and an HTTP status in the range 100–599 when supplied. A paid request with an invalid or missing result can remain unresolved across restart. Readers distinguish an insufficient byte budget from invalid retained evidence.
- Hosts can bind capability names to retained asset IDs. Deployments consuming a corpus must select its assets explicitly when creating a new store. Scoped formats record versions and preserve selected request bytes across recovery. Historical stores preserve their original interpretation.
- Campaign archives remain in the runtime Git repository under the same paths. The consumable Go module includes application code, examples and runtime regression fixtures.

Use Go 1.27.3 or newer with CGO, a C compiler and a local Unix filesystem supporting SQLite WAL, durable sync and exclusive owner locks. Follow the [upgrade policy](compatibility.md) and [packaged-consumer procedure](consumer.md). The candidate and published-tag qualifications are separate records.
